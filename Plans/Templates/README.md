# Plan Templates

This folder contains starter templates for a new plan package.

Primary starter:
- `Plans/Templates/plan-folder/`

How to use:
1. Copy `plan-folder` into the target stage folder (for example `Plans/Drafts/`).
2. Rename the copied folder to the semantic plan name.
3. Fill out `plan.md`, including dependency references and interface/contract sections.
4. Add/rename step folders under `steps/` using `NNNN-semantic-step-name`.
5. Keep all step artifacts inside each step folder.
